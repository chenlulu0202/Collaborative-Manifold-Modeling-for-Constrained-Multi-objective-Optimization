# Collaborative-Manifold-Modeling-for-Constrained-Multi-objective-Optimization

This is the official code repository of CMMEA. 

Since the associated manuscript is currently undergoing peer review, the full source code will not be released until the paper is accepted. After acceptance, we will upload all training scripts, inference code, dataset processing files, and experimental configurations to this repository.

Main algorithm implementation (MATLAB/Python)
Baseline algorithm interfaces (C-TAEA, PPS, ToP, CCMO, CMOES, MOEA/D-2WA, MACA, etc.)
Benchmark problem suites (MW, LIRCMOP, DASCMOP)
Parameter configuration files
Raw run-level results (HV, IGD, convergence curves)
Reproduction instructions

This README will be updated once the paper is accepted and the code is made publicly available.
